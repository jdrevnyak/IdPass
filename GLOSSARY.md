# Classroom hall passes

A reader in a classroom records when a student leaves the room and prints the slip they carry.

## Language

**Classroom**:
The room a reader is assigned to. An outing belongs to the classroom it started from.
_Avoid_: Destination

**Teacher**:
The adult named for this classroom. One teacher card stands in for them.
_Avoid_: Staff, user

**Teacher card**:
The single card enrolled for a classroom reader. A tap on that reader opens the teacher menu, ahead of any student link, and the same card may be enrolled for more than one classroom.
_Avoid_: Teacher, staff card

**Teacher menu**:
The actions reserved for the teacher card: end this classroom's active outings, issue a pass out, and reprint the last hall pass.
_Avoid_: Settings

**Outing**:
A recorded visit that takes a student out of this classroom. Bathroom, Nurse, Water, and Guidance are outings.
_Avoid_: Break, hall pass, visit

**Pass Out**:
A printed permission for one named student to go to one named room. It is not an outing.
_Avoid_: Hall pass, outing

**Destination**:
The room a pass out sends a student to. It is not this classroom.
_Avoid_: Classroom

**Hall pass**:
The printed slip for an outing or a pass out.
_Avoid_: Outing
